How to use this Jobs board
  1. Save each spool first. Save from the drawing screen so the spool appears in the job list and production board.
  2. Move the spool through stages. Drag a card to another stage, or use the Stage menu on the card. You can also change the open drawing from the top Status menu.
  3. Allocate the work. Use the card fields for Assigned, Due, Priority and Hold. The same details are also in Review > Checks > Workflow.
  4. Use messages for yard notes. Add a message to a card, mark it Done when handled, and it will be set to disappear after one week.
  5. Use More for team tools. Open More for the Jobs guide, Team comms and daily or weekly reports without crowding the main toolbar.

Quick rule: the board is for tracking production. Use Open when you need to edit the drawing itself.

Privacy, terms and support How SpoolMate handles account data and where to get help.

Privacy summary

Guest drawings are stored in this browser. When you sign in, SpoolMate stores your email, trial/licence status, cloud drawings, team membership, comments and any workshop photos you choose to upload in Supabase.

Cloud data is used to authenticate you, synchronise projects and support team collaboration. Workshop photos are stored in a private bucket and access is controlled by project and company permissions.

Ask SpoolMate uses built-in help first. If a signed-in user asks for extra AI help, the question, a short recent help conversation and limited app context such as the current mode and tool are sent through a protected Supabase function to OpenAI. Drawing geometry, project names, notes, photos and authentication tokens are not sent automatically. Do not type customer-confidential information into the helper.

You can download an account-data export from Account. Deleting your cloud account permanently removes the account and its owned cloud data; local browser projects remain on this device.

Trial and licence access

New accounts receive a 30-day cloud trial. The app warns as the trial approaches its end.

Trial expiry does not delete cloud drawings. Permitted projects, comments and workshop photos remain available to open, view and export in read-only mode. Cloud saving, editing, new comments/photos and team changes resume when the licence is activated.

No automatic inactive-account deletion is currently enabled. Users can export their data or permanently delete their own cloud account from Account.

Important fabrication terms

SpoolMate is a drawing and fabrication-assistance tool, not engineering certification. Check dimensions, specifications, material selections, weld/NDT requirements, lifting calculations and issued PDFs before fabrication, ordering or lifting.

Your organisation remains responsible for approvals, applicable standards and workshop use of exported information.

Support and problem reports

Download a diagnostic report before requesting help. It contains app/device status and drawing counts, but excludes drawing geometry, notes, photos, passwords and authentication tokens.

Open support page
GitHub issues are public. Do not include customer drawings, photos, passwords, tokens or commercially sensitive project information.

Pre-launch action: have the final privacy policy and terms reviewed and add the operator's business name and support email before a public paid launch.

SpoolMate help Quick instructions for PC, iPad and phone workflows.

Using iPad or phone

Simple and Full controls

Simple keeps the drawing clear and puts pipe size, dimensions and display choices inside Pipe & display. Open Menu > Workspace controls whenever you want to switch to Full and see every setting at once.

Change a flange

Tap Select, zoom in if needed, then press and hold directly on the flange marker until the menu opens. Tap Flange standard, then pick Table E, PN 16, ANSI 150 or another type. The 3D model uses that table's actual flange OD, thickness, bolt PCD, hole diameter and hole count.

Add fittings

Press and hold on a pipe run or pipe end. Use Add fitting for flanges, roll grooves, threaded pipe ends, reducers and sockets.

Move sockets and dimensions

With Select active, drag a socket along the pipe. Drag fabrication dimension labels away from clashes when line dimensions are on.

Move and fit the 2D drawing

With Select active, drag empty paper to move the spool. Use two fingers together to pan and pinch to zoom. Tap Fit above the drawing whenever you want the whole spool and its callouts back on screen.

3D view

Tap 3D above the drawing. Drag to rotate, use Move to pan, pinch to zoom, and Fit to centre the whole spool.

If the menu does not open

Make sure Select is active, keep your finger still for the long press, and press on the fitting or pipe itself rather than empty paper.

Open Help quickly

Tap Menu, then Help. On iPad or phone, Help opens to this touch section first.

Draw a 45 degree offset

Enter the offset set, then press and hold Hold 45° beside the drawing controls with one finger while dragging the angled travel with another. Release it before drawing the straight return.

Draw mode

Draw pipe runs

Pick Draw, then drag from the active point. On PC, press Enter to stop drawing and return to Select.

Exact lengths

Set Next run mm, then use +X, -X, +Y, -Y, +Z or -Z for exact centre-to-centre runs.

45 degree offsets

Enter the offset set in Next run / offset set mm. Hold Shift on a keyboard, or hold the Hold 45° drawing control on touch, while dragging the angled travel. Release it for the straight return. SpoolMate calculates travel as set x 1.414 and stores both values.

Project details

New drawings ask for job and spool details. These print at the top right of the drawing and export sheets.

Offset measurements

Turn Dimensions on. The angled run shows the travel C/C, and fabrication line dimensions also show the offset set C/C between centres.

Measure tool

Pick Measure, click or tap the first point, then click or tap the second point. SpoolMate leaves that measurement marked on the plan.

Undo and redo

Use Undo or Redo in the side tools if a run, fitting or note was placed wrong.

Focus mode

Press Focus beside the drawing controls to fill the screen with the drawing and a slim tool rail. Press Exit or Escape when finished.

3D overlay

Press 3D beside Focus to open the movable preview over the drawing. Resize it from the corner; SpoolMate remembers its last size and position on that device.

Edit and fittings

Select and multi-select

Pick Select, then tap or click a run. Hold Shift on PC to add more runs, or use Box Select to lasso a group.

Pipe size changes

Right-click or long-press a run, choose Change pipe size, then pick from the pipe or tube size list. At a welded branch, either straight-through main section updates the whole continuous main while the side outlet stays separate.

Flanges and grooves

Right-click or long-press a pipe end to add a single flange, double flange, roll groove or threaded pipe end. Existing flanges can be changed from the flange pick menu.

Sockets

Right-click or long-press a run, choose Add sockets, then use the picture menu to pick socket size, quantity and spacing.

Tee or branch

Use the Tee or Branch tools while in Draw mode. A tee splits the pipe and adds tee takeoff and weight. A branch is treated as a welded pipe into the side of the main run.

Reducers

Reducers are added when pipe sizes change. Choose concentric or eccentric in Pipe & display, or right-click/long-press the reducer to change its type. Eccentric reducers show their flat side and offset e; bend reducers can also be moved to the other leg.

Notes

Use Note to type drawing notes. With Select active, drag notes to clean up the drawing.

Flange defaults

Set the default single/double flange and standard in Angles and fittings before placing several flanges.

Review mode

Checks

Open Check from the Menu to find drawing issues. Show on drawing highlights the finding without leaving Review or the Checks list; fix buttons remain separate.

Intentional exceptions

Use Acknowledge & allow issue only when the arrangement is intentional. A reason, reviewer and time are saved with the spool. App test-kit failures remain visible but do not block that spool.

Cut list and takeoff

Use Cut List and Weights to see pipe cut lengths, bend deductions, fittings, flange types, tee counts and estimated weight.

Lifting points

Open Review and turn Lifting points on from its settings strip. Change sling angle to see suggested lug points and dimensions update.

Lock edits

Set a drawing to Checked or Issued, then use Lock edits when you want to stop accidental changes.

Dimension styles

Use the Draw or Export settings strip: choose Drawing detail first, then Dim view. Pipe labels can show key sizes, all sizes, export-only labels or stay hidden while drawing.

Takeoff list

The takeoff list groups pipes and fittings by size and type, including flange standards, tees, bends, reducers, sockets, roll grooves and threaded pipe ends.

Weight notes

Pipe and fitting table weights are used where available. Estimated or adjusted weights should be checked before ordering or lifting.

Defaults

Use Menu, Defaults to save your usual material, pipe/tube size, dimensions, lifting and preview settings on that device.

Export mode

Fab PDF

Choose a PDF style in the Export settings strip, then use Fab PDF for centre-to-centre dimensions, cut list, weights, takeoff and project details.

3D image

Use Export 3D for a preview image. Turn pipe labels on or off from the 3D preview controls before exporting.

Project file

Export Project file when you need to send a drawing that can be imported back into SpoolMate later.

Read-only share

Use Share to create a shop/client copy that can be viewed without changing the live project.

Clean export drawings

Before exporting, turn off 3D pipe labels if the model is too busy and drag fabrication dimensions away from overlaps.

Fab sheet contents

The fabrication sheet includes centre-to-centre measurements, cut lengths, bend deductions, weights and a fitting takeoff.

Account and cloud

Guest mode

Continue as guest keeps drawings on that device/browser. Use Save and Open for local project folders.

Sign in

Signing in lets projects save to your cloud account and makes them available on other devices.

Password recovery

Open Account and choose Forgot password. Use the emailed recovery link to return to SpoolMate and set a new password.

Team workspace

Company accounts let a team share projects and comments while drawings are being worked on.

Updates

If a newer version is available, SpoolMate will tell you to refresh or reload so the latest app files are used.

Local versus cloud

Local saves stay on the current browser. Cloud saves are the better choice when you want the same jobs on PC, iPad and phone.

Team notes

Open Jobs, then Comms for team messages and the current spool conversation. Use @mentions, attach workshop photos and resolve messages once addressed.

Review and approval

Checkers can approve a drawing or return it with a required comment. Issued drawings stay locked; returning one preserves it and starts the next revision.

Privacy and account data

Account includes data export, diagnostics and cloud-account deletion. Privacy & support explains what stays local and what is stored in Supabase.
