Guide
How to use this Jobs board
  1. Save each spool first. Use Save current so the spool appears in the job list and production board.
  2. Move the spool through stages. Drag a card to another stage, or use the Stage menu on the card. You can also change the open drawing from the top Status menu.
  3. Allocate the work. Use the card fields for Assigned, Due, Priority and Hold. The same details are also in Review > Checks > Workflow.
  4. Use messages for yard notes. Add a message to a card, mark it Done when handled, and it will be set to disappear after one week.
  5. Open Comms for the team view. Use Comms to post general team messages and see all active spool notes in one place.

Quick rule: the board is for tracking production. Use Open when you need to edit the drawing itself.

SpoolMate help Quick instructions for PC, iPad and phone workflows.

Using iPad or phone

Change a flange

Tap Select, zoom in if needed, then press and hold directly on the flange marker until the menu opens. Tap Flange standard, then pick Table E, PN 16, ANSI 150 or another type.

Add fittings

Press and hold on a pipe run or pipe end. Use Add fitting for flanges, roll grooves, reducers and sockets.

Move sockets and dimensions

With Select active, drag a socket along the pipe. Drag red dimension labels away from clashes when red line dimensions are on.

3D view

Drag to rotate, middle mouse or Move to pan, wheel or pinch to zoom, and Fit to centre the whole spool.

If the menu does not open

Make sure Select is active, keep your finger still for the long press, and press on the fitting or pipe itself rather than empty paper.

Open Help quickly

Tap Menu, then Help. On iPad or phone, Help opens to this touch section first.

Draw mode

Draw pipe runs

Pick Draw, then drag from the active point. On PC, press Enter to stop drawing and return to Select.

Exact lengths

Set Next run mm, then use +X, -X, +Y, -Y, +Z or -Z for exact centre-to-centre runs.

45 degree offsets

Enter the offset set in Next run / offset set mm. For 45 degrees, SpoolMate calculates travel as set x 1.414 and stores both values.

Project details

New drawings ask for job and spool details. These print at the top right of the drawing and export sheets.

Offset measurements

Turn Dimensions on. The angled run shows the travel C/C, and red-line dimensions also show the offset set C/C between centres.

Measure tool

Pick Measure, click or tap the first point, then click or tap the second point. SpoolMate leaves that measurement marked on the plan.

Undo and redo

Use Undo or Redo in the side tools if a run, fitting or note was placed wrong.

Edit and fittings

Select and multi-select

Pick Select, then tap or click a run. Hold Shift on PC to add more runs, or use Box Select to lasso a group.

Pipe size changes

Right-click or long-press a run, choose Change pipe size, then pick from the NB list. Size changes add reducers where needed.

Flanges and grooves

Right-click or long-press a pipe end to add a single flange, double flange or roll groove. Existing flanges can be changed from the flange pick menu.

Sockets

Right-click or long-press a run, choose Add sockets, then use the picture menu to pick socket size, quantity and spacing.

Tee or branch

Use the Tee or Branch tools while in Draw mode. A tee splits the pipe and adds tee takeoff and weight. A branch is treated as a welded pipe into the side of the main run.

Reducers

Reducers are added when pipe sizes change. If a bend reducer lands on the wrong side, right-click or long-press it and move it to the other side.

Notes

Use Note to type drawing notes. With Select active, drag notes to clean up the drawing.

Flange defaults

Set the default single/double flange and standard in Angles and fittings before placing several flanges.

Review mode

Checks

Open Check from the Menu to find missing project details, estimated weights, tiny runs and other issues. Tap an issue to highlight the area.

Cut list and takeoff

Use Cut List and Weights to see pipe cut lengths, bend deductions, fittings, flange types, tee counts and estimated weight.

Lifting points

Turn Lifting points on from the top bar. Change sling angle to see suggested lug points and dimensions update.

Lock edits

Set a drawing to Checked or Issued, then use Lock edits when you want to stop accidental changes.

Dimension styles

Use Drawing detail first: Clean, Fab dims, Sizes, Callouts or Full. Use Dim style when you want to fine tune the dimension format.

Takeoff list

The takeoff list groups pipes and fittings by size and type, including flange standards, tees, bends, reducers, sockets and roll grooves.

Weight notes

Atlas table weights are used where available. Estimated or adjusted weights should be checked before ordering or lifting.

Defaults

Use Menu, Defaults to save your usual material, NB size, dimensions, lifting and preview settings on that device.

Export mode

Fab PDF

Exports the drawing with centre-to-centre dimensions, cut list, weight summary, takeoff list and project details.

3D image

Use Export 3D for a preview image. Turn pipe labels on or off from the 3D preview controls before exporting.

Project file

Export Project file when you need to send a drawing that can be imported back into SpoolMate later.

Read-only share

Use Share to create a shop/client copy that can be viewed without changing the live project.

Clean export drawings

Before exporting, turn off 3D pipe labels if the model is too busy and drag red dimensions away from overlaps.

Fab sheet contents

The fabrication sheet includes centre-to-centre measurements, cut lengths, bend deductions, weights and a fitting takeoff.

Account and cloud

Guest mode

Continue as guest keeps drawings on that device/browser. Use Save and Open for local project folders.

Sign in

Signing in lets projects save to your cloud account and makes them available on other devices.

Team workspace

Company accounts let a team share projects and comments while drawings are being worked on.

Updates

If a newer version is available, SpoolMate will tell you to refresh or reload so the latest app files are used.

Local versus cloud

Local saves stay on the current browser. Cloud saves are the better choice when you want the same jobs on PC, iPad and phone.

Team notes

Project comments are for simple workshop notes while a spool is being drawn, checked or revised.
